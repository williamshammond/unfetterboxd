# Chrome Web Store Listing Draft

## Name

Visible Ratings for Letterboxd

## Short Description

Shows your existing Letterboxd ratings directly on list pages.

## Detailed Description

Visible Ratings for Letterboxd adds your existing star ratings directly beneath posters on Letterboxd list pages.

The extension only runs on Letterboxd list URLs. It reads rating information already present in the page shown in your browser and injects visible rating text locally.

It does not collect analytics, transmit data, use a backend, or store your ratings externally.

This extension is independent and is not affiliated with Letterboxd.

## Privacy Summary

Single purpose: show existing Letterboxd ratings directly on list pages.

Data usage: reads the current Letterboxd page DOM locally.

Data collection: none.

Data transmission: none.

Backend/API usage: none.
